# 台本

「星空撮影入門。スマホを外に放置するだけで星空を撮る」の台本です。章ごとに1ファイル、番号順に再生します。

## 書式

- `## 場面: 名前` で場面を区切ります。場面は画面(アニメーション)の単位です。
- `> 画面:` はその場面で映すもの、`> 効果音:` は鳴らす音の指示です。音声にはなりません。
- `めたん:` `つむぎ:` で始まる行が台詞です。1行が字幕1枚・音声1本になります。
- 読みを指定したい語は `{表記|よみ}` と書きます。字幕には表記、音声には読みを使います。
- 全体で使う読み(RAW=ロー など)は `video/tools/dictionary.json` に登録するので、台本には書きません。

## 役割

- 四国めたん: 解説役。
- 春日部つむぎ: 視聴者と同じ目線で質問する役。

## 実画像のルール

画面に出す実画像は、空だけが写っているものに限ります(`raw_data4` と、空の領域の切り出し)。前景が必要な説明は、架空の家を描いた模式図で行います。
